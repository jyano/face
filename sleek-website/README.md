# Lumen — Super Sleek Modern Web

A minimal, high-contrast static website with glassmorphism, tasteful motion, and responsive layout. No build step required.

## Quick start

- Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 5173 --directory /workspace/sleek-website
```

## Customize

- Edit `styles.css` for theming (`--brand`, `--brand-2`, typography, spacing)
- Update sections in `index.html` (hero, features, showcase, testimonials, CTA)
- `app.js` controls reveal animations, tilt, sticky header, and mobile nav

## Deploy

- Drag-and-drop to any static host (GitHub Pages, Netlify, Vercel static, S3, Cloudflare Pages)
- Set a custom domain, enable HTTPS, and you're done
